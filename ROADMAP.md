# CrackMap roadmap

## Before sharing the link publicly
- [ ] Impressum and privacy page (have the texts checked; mention that photo content stays visible)
- [ ] Backups of the live database and photos
- [ ] Spam protection for sign-up (rate limits / simple check)

## Future features
- [ ] Address search bar on the map (geocoding, e.g. OpenStreetMap Nominatim; check its usage policy)
- [ ] Three climb categories with coloured pins: boulder (yellow), indoor (green), outdoor (red)
- [ ] Email at sign-up (decide: optional for password reset, or required + verified)
- [ ] Tamper-proofing: edit history per crack, report button, rate limits, moderation queue
- [ ] Export/import of the whole dataset (JSON/GeoJSON + photos) for backup, restore or moving to another app
